- **Featured projects**

  - Doctor Appointment Website
  - Weather Dashboard

  - AI Trip Planner (Prototype)
  - Netflix Homepage Clone
- **Experience**: AI Intern, Excellence Technology
- **Education**: MCA, BCA, Class 12, Class 10
- **Achievements and certifications**
- **Contact**: email, GitHub, WhatsApp and phone

## Built with

- HTML5, CSS3 and vanilla JavaScript in a single file, with no build step and no dependencies
- Google Fonts (Bricolage Grotesque and IBM Plex Sans)
- Responsive layout, light and dark colour themes (follows the device setting), keyboard focus styles and reduced-motion support

## Run locally

1. Download or clone this repository.
2. Open `index.html` in any modern browser.

To serve it locally instead, run `python -m http.server 8000` in the project folder and visit `http://localhost:8000`.

## Customise

All content lives in `index.html`:

- **Contact details**: search for `priyanshukumar45000@gmail.com`, `917033548627` and the GitHub URL, and replace as needed.
- **Projects**: copy an `<article class="proj">` block inside the `#work` section and edit the title, description and tags.
- **Colours**: change the values in the `:root` block at the top of the `<style>` tag. Dark-theme values are in the two blocks below it.
- **LinkedIn**: add a button inside the `.links` div in the `#contact` section.

## Deploy for free

**GitHub Pages**
1. Push `index.html` to a repository on GitHub.
2. Open **Settings → Pages**, choose the `main` branch and the root folder, then save.
3. Your site appears at `https://<username>.github.io/<repository>/`.

**Netlify or Vercel**: drag the project folder into the dashboard, or connect the repository. No build command is needed.
